# JHU_Honors_Thesis_Code
This is my code repository for my Honor's Thesis data analysis code on Dipodomys skeletal morphology.

This is my code used for my honor’s thesis. The code is commented throughout and should be readable and straightforward. Broadly, the code cleans data and log-transforms it to analyze lengths of hindlimbs of different Dipodomys species using a phylogenetic PCA and then PERMANOVA to determine if there are morphometric differences across species or across different deserts. It then restricts the data to only D. merriami data, as this was the only species with measured specimens present across the three deserts of interest and runs an ANOVA to determine if there are morphological differences in the hindlimb across the three different populations.
